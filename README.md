# MandiMart

Direct farmer-to-buyer marketplace demo. Static site - runs on GitHub Pages.

Crops you add are saved in your browser (localStorage), so they stay after a refresh.
Login/register run in demo mode. The AI Compare page needs the Flask API running separately.

## Publish on GitHub Pages
1. Upload all files in this folder to the ROOT of a GitHub repo (index.html must be at the top level).
2. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
3. Open https://<your-username>.github.io/<repo-name>/ after a minute.
